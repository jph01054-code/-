# 스마트스토어 재입고 구매 도우미 — Windows 소스 배포

이 파일은 대화에 남은 구현을 바탕으로 복원한 배포본입니다. EXE가 아니며 Python 설치가 필요합니다.

## 설치

1. Windows 10/11에서 Python 3.11 이상을 설치하세요. Tcl/Tk와 Python Launcher를 포함하세요.
2. ZIP 전체를 일반 폴더에 압축 해제하세요. 압축 폴더 안에서 바로 실행하지 마세요.
3. `install.bat` 실행으로 Playwright와 Chromium을 설치하세요. 인터넷이 필요합니다.
4. `start.bat`을 실행하세요.

## 사용

상품 링크, 정확한 옵션, 수량, 한도 금액, 오픈 날짜·시각을 확인하세요. PC를 한국시간으로 설정하세요. 기본 날짜는 실행일이며 반드시 확인해야 합니다. 오픈 시각이 지났으면 즉시 감시 여부를 확인합니다.

‘저장·브라우저 열기’로 열린 전용 브라우저에서 직접 로그인하고 상품 화면으로 돌아온 후 F8 또는 ‘시작’을 누르세요. 오픈 1분 전부터 새로고침합니다. 10:00 오픈이면 09:59부터 시작합니다. 감시 중 옵션 구매가 가능해지면 즉시 주문 화면 진입을 시도하므로 오픈 전에도 진입할 수 있습니다. 실행 중 UI 설정 변경은 적용되지 않습니다. F10으로 종료하고 다시 여세요.

F8 시작, F9 일시정지/재개, F10 긴급 중지입니다. Windows 전역 핫키가 다른 프로그램과 충돌하면 화면 버튼을 사용하세요. 진행 중인 요청·클릭은 취소되지 않을 수 있습니다. 종료는 최대 약 20초 걸릴 수 있고, 이미 생성된 주문은 취소되지 않습니다.

## 지원 범위 및 제한

- 재입고 감시 → 정확한 옵션 선택 → 수량 입력 → 주문 화면 진입을 세션당 한 번 시도합니다.
- 기본 새로고침은 응답 완료 후 2초, 최소 1초입니다. 순차 요청을 사용하며 오류 시 간격을 늘립니다. 0.1초 입장이나 특정 마지막 새로고침 시점은 보장하지 않습니다.
- 접근 제한 401/403/429, 5회 연속 오류, 옵션·수량 식별 실패 시 자동화를 중단합니다. 로그인·CAPTCHA·추가 인증은 직접 진행해야 합니다.
- **최종 자동 결제는 구현되지 않았습니다.** 한도 금액은 표시용이며 최종 총액을 자동 검증하지 않습니다. 배송비 포함 총액이 한도 이하인지 직접 확인하세요. 카드·택배도 주문 화면에서 직접 선택하세요.
- 주문 진입 결과가 불확실해도 자동 재시도하지 않습니다. 프로그램을 재실행하기 전 주문 내역을 확인하세요.
- 실제 네이버 화면 및 Windows GUI·핫키는 이 환경에서 검증하지 못했습니다. 버튼이나 옵션의 구조가 다르면 중단될 수 있습니다. 이 버전은 주문 성공을 보장하지 않습니다.

기본값: 스킨푸드 상품 13763129062, 감자 수딩 패드 60매(+마스크팩2매), 수량 1개, 배송비 포함 한도 50,000원, 카드·택배.

설정과 로그인 프로필은 `%LOCALAPPDATA%\SmartStoreAssistant`에 저장됩니다. 카드 번호와 비밀번호는 프로그램에 저장하지 않지만 브라우저 프로필에는 로그인 세션이 포함될 수 있습니다. 해당 폴더를 공유하지 마세요.

## 로컬 테스트

`python -m unittest discover -s tests -v`로 설정 검증을 실행합니다. 이 복원본의 테스트 결과는 이전 배포본의 17개 테스트 결과와 별개입니다.
